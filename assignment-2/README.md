# Access Control Logging

This project provides a file access monitoring and logging system, which records all file access attempts and allows for analysis of unauthorized access attempts and file modifications by users.

## Components

### 1. `logger.c`
- **Purpose**: This is a shared library that intercepts file operations (`fopen` and `fwrite`) to log file access and modifications in real-time.
- **Features**:
  - Logs details like the user ID, date, time, access type, and SHA-256 hash (fingerprint) of the file content.
  - Generates a log file (`file_logging.log`) with records of file access events.
  - Hashes the file content using SHA-256 to create a unique fingerprint for each file modification.

### 2. `acmonitor.c`
- **Purpose**: This is a command-line monitoring tool to analyze logs generated by `logger.c`.
- **Features**:
  - Lists users with unauthorized access attempts using the `-m` option.
  - Lists users who have modified a specified file and counts the number of modifications using the `-i <filename>` option.
  - Displays results on the console with each user’s modification count or unauthorized access count.

### 3. `test_aclog.c`
- **Purpose**: This is a test script to create, deny, and grant file access permissions, used to generate sample log data.
- **Features**:
  - Creates test files (`test_1.txt` to `test_7.txt`) with sample content.
  - Simulates unauthorized access by removing file permissions.
  - Restores permissions and logs successful write attempts.

## Makefile

The provided Makefile simplifies compilation and execution of the project.

### Targets

- **`all`**: Compiles all components (`logger.so`, `acmonitor`, `test_aclog`).
- **`logger`**: Compiles `logger.c` as a shared library.
- **`acmonitor`**: Compiles `acmonitor.c`.
- **`test_aclog`**: Compiles `test_aclog.c`.
- **`run`**: Sets the `LD_PRELOAD` environment variable to intercept file access functions and runs `test_aclog` to generate log data.
- **`clean`**: Removes compiled files.

### Running the Makefile

1. **Compile All Components**:
   ```bash
   make all
2. **Run the Test Log Generator**:
    make run
3. **Using acmonitor to List Malicious Users**:
    make malicious
4. **Using acmonitor to Analyze a Specific File(Replace <filename> with the desired file)**:
    make monitor-file file=<filename>
5. **Clean up**:
    make clean
